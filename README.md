# Tomer DayBoard

אפליקציית React + Vite בעברית.

## הרצה מקומית

```bash
npm install
npm run dev
```

## העלאה ל-GitHub ופריסה ב-Vercel

1. צור Repository חדש ב-GitHub.
2. העלה אליו את כל הקבצים שבתיקייה הזאת.
3. היכנס ל-Vercel ולחץ Add New Project.
4. בחר את ה-Repository.
5. Framework: Vite.
6. Build Command: `npm run build`.
7. Output Directory: `dist`.
8. לחץ Deploy.

## באייפון

פתח את הקישור של Vercel בספארי → Share → Add to Home Screen.
